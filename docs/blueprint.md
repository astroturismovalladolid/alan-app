# **App Name**: ALAN

## Core Features:

- Image Upload: Allow users to upload images of light pollution.
- Location Tagging: Enable users to tag the location of the light pollution in the uploaded image.
- Rating System: Implement a rating system for users to rate the severity of the light pollution in each image.
- AI-Powered Analysis: Employ a tool powered by AI to analyze the images and automatically detect and assess the intensity of light pollution.
- Community Forum: Provide a forum for users to discuss and share information about light pollution.

## Style Guidelines:

- Primary color: Deep navy blue (#24305E) to represent the night sky.
- Background color: Dark gray (#333333) for contrast and to evoke the night.
- Accent color: Bright yellow (#FFD700) to highlight the light pollution and CTAs.
- Font pairing: 'Space Grotesk' for headlines and 'Inter' for body text, both sans-serif, to create a clean and modern look.
- Use minimalist icons related to locations, images, and ratings.
- Simple and intuitive layout, focusing on image presentation and easy navigation.
- Subtle transitions and animations for a smooth user experience when uploading or viewing images.
